2. 연관분석 (지지도 • 신뢰도 • 향상도)

3과목 의사결정나무 개념 & 계산 빈출

3. 불순도 지표 (지니 지수 • 엔트로피)

지니 지수 (Gini Index): Gini = 1 - ∑ (p_i)²

2개 범주일 때 p_1 = p, p_2 = 1 - p 이면 Gini = 2p(1 - p). p = 0.5일 때 최대값 0.5

엔트로피 (Entropy): Entropy = - ∑ p_i × log₂(p_i)

2개 범주일 때 p = 0.5일 때 최대값 1.0 (가장 혼잡한 상태)

2개 범주 지니지수 즉시 계산기
A 범주 비율 (p): 0.50 B 범주 비율 (1-p): 0.50

3과목 통계 분석 빈출 핵심

4. 통계 필수 수식 (결정계수 • IQR • VIF)

회귀 결정계수 (R²): R² = SSR / SST = 1 - (SSE / SST)

• 총변동(SST) 중 회귀식으로 설명되는 변동(SSR)의 비율 (0 ≤ R² ≤ 1)
• 다중공선성(VIF): VIF > 10 이면 다중공선성 존재 의심 (변수 제거 또는 축소)

이상치(Outlier) 판단 IQR 공식: IQR = Q3 - Q1

• 정상 범위 하한: Q1 - 1.5 × IQR
• 정상 범위 상한: Q3 + 1.5 × IQR (이 범위를 벗어나면 이상치 판정!)

시계열 정상성(Stationarity) 3대 조건:

1. 평균이 일정하다. (일정하지 않으면 차분(Difference) 수행)
2. 분산이 일정하다. (일정하지 않으면 로그/제곱근 변환 수행)
3. 공분산은 시점 t에 의존하지 않고 오직 시차(Lag)에만 의존한다.

1 제1과목: 데이터의 이해 (손글씨 따라쓰기)

두문자: 데정지지 • 공표연내 • 사책알
1. DIKW 피라미드 (데 - 정 - 지 - 지)

• Data (데이터): 순수한 객관적 [ 사실 (Fact) ] (예: A마트 100원, B마트 200원)
• Information (정보): 데이터를 가공하여 [ 의미 (Context) ] 부여 (예: A마트가 더 싸다)
• Knowledge (지식): 정보를 구조화하여 [ 개인적 경험으로 체득 ] (예: A마트에서 사야겠다)
• Wisdom (지혜): 지식을 바탕으로 미래를 [ 예측 및 창의적 판단 ]

2. 암묵지와 형식지의 상호작용 (공 - 표 - 연 - 내)

• 공통화 (Socialization): 암묵지 → 암묵지 (경험 공유, 신체적 전수)
• 표출화 (Externalization): 암묵지 → 형식지 ([ 문서화, 매뉴얼화 ])
• 연결화 (Combination): 형식지 → 형식지 (문서 결합 및 체계화)
• 내면화 (Internalization): 형식지 → 암묵지 (독서/훈련을 통한 자기 것 화)

3. 빅데이터 위기요인 3가지와 통제방안 (사 - 책 - 알)

• 사생활 침해 ➔ 해결책: [ 책임 원칙 ] (동의제도에서 책임제도로 전환)
• 책임 원칙 훼손 ➔ 해결책: [ 결과 기반 책임 ] (예측만으로 처벌 불가)
• 알고리즘 블랙박스 ➔ 해결책: [ 알고리즈미스트 ] 제도 도입 (설명책임 부여)

2 제2과목: 데이터 분석 기획 (손글씨 따라쓰기)

두문자: 최솔인발 • 준도확정 • 조프시대인
1. 분석 과제 발굴 4가지 방식 (최 - 솔 - 인 - 발)
• 대상 O, 방법 O ➔ [ 최적화 (Optimization) ]
• 대상 O, 방법 X ➔ [ 솔루션 (Solution) ]
• 대상 X, 방법 O ➔ [ 통찰 (Insight) ]
• 대상 X, 방법 X ➔ [ 발견 (Discovery) ]
2. 분석 거버넌스 성숙도 / 준비도 4분면 (준 - 도 - 확 - 정)

• 준비도 낮음 + 성숙도 낮음 ➔ [ 준비형 ]
• 준비도 높음 + 성숙도 낮음 ➔ [ 도입형 ] (인프라는 있으나 분석 역량 초기)
• 준비도 낮음 + 성숙도 높음 ➔ [ 확산형 ] (조직 역량은 있으나 시스템 미비)
• 준비도 높음 + 성숙도 높음 ➔ [ 정착형 ] (최상위 단계)

3 제3과목: 데이터 분석 & 필수 계산 공식 따라쓰기

두문자: 정모예 • 민실재 • 지전신A
1. 혼동행렬 지표 직접 써보기

• 정밀도(Precision) = [ TP / (TP + FP) ] (분모: 모델이 True라고 예측한 합)

• 재현율(Recall/민감도) = [ TP / (TP + FN) ] (분모: 실제 True의 합)

• F1-Score = [ 2 × (정밀도 × 재현율) / (정밀도 + 재현율) ] (조화평균)

2. 연관분석 3대 지표 직접 써보기

• 지지도 (Support) = [ A와 B 동시 구매건수 / 전체 건수(N) ]

• 신뢰도 (Confidence) = [ A와 B 동시 구매건수 / A 구매건수 ]

• 향상도 (Lift) = [ 신뢰도 / B의 지지도 = P(A ∩ B) / (P(A) × P(B)) ]
